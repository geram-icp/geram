# GERAM Architecture Map

## Purpose

This document defines the architecture scope that belongs to the
GERAM project itself.

GERAM is the core real-economic asset and RWA infrastructure of the
ecosystem.

## GERAM Responsibilities

- Asset registration
- GERAM-ID
- Asset passport
- Rights
- Evidence
- Verification
- Attestation
- Valuation
- Eligibility
- Authorization
- Certificate
- RWA representation
- Asset lifecycle
- Measurement
- Realized value
- Audit and traceability

## Main Asset Sectors

- Energy
- Housing
- Logistics
- Production
- Tourism
- Infrastructure
- Technology
- Other real economic assets

## GERAM Source of Truth

GERAM is the source of truth for:

- GERAM assets
- GERAM-ID
- Registered rights
- Evidence references
- Verification state
- GERAM certificates
- RWA registration state
- Asset lifecycle state

## External Dependencies

GERAM may integrate with:

- NFID
- HamiFund
- FlowChain
- Banks
- Financial institutions
- Government systems
- Official registries
- External data providers
- Oracle services

External systems remain authoritative for their own records.

## Boundary

GERAM does not become the source of truth for:

- Bank balances
- Blockchain balances outside GERAM
- HamiFund financial positions
- External legal registries
- External payment states
- External accounting records

## Core Rule

Digital Representation != Underlying Asset
